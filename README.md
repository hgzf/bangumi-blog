# 苞谷米日志

一个纯本地运行的 Bangumi 个人博客、碎碎念和追番档案桌面客户端。应用使用 Electron、Vue 3、Tailwind CSS、Marked.js 和 DOMPurify。

## 开发运行

需要 Node.js 22 或更高版本，并推荐使用 pnpm：

```powershell
pnpm install
pnpm start
```

`pnpm start` 会先构建 Tailwind CSS，再启动 Electron。

首次启动无需联网即可进入界面。连接 Bangumi 时，在右上角设置中填写用户名或 Access Token；Token 仅保存在本机 `localStorage`，不会写入导出备份。

Windows 本地使用可以在依赖安装完成后双击 `启动苞谷米日志.vbs`，不会显示 CMD 控制台。项目目录中的 `.lnk` 快捷方式包含本机绝对路径，因此不会提交到 Git。

单独构建样式或运行测试：

```powershell
pnpm run build:css
pnpm test
```

## 数据位置

主数据保存在 Electron 用户数据目录下的 `bgm_blog_database.json`。具体路径可在“系统设置 → 本地数据与备份 → 打开数据库位置”查看。

备份包含文章、图片、收藏、条目缓存、主题和自定义表情。长文可单篇或批量导出为 Markdown。

日志、收藏、图片和生成的报告默认只保存在本机。使用 Bangumi 同步或春菜 AI 时，相应请求会发送到用户配置的服务；详细说明见 [SECURITY.md](SECURITY.md)。

桌面、浏览器预览和未来 Android 端通过 [平台桥接契约](docs/platform-bridge.md) 共用页面代码。

## 主要功能

- 即时博客、番组档案、站内作品详情、周月记和年度年鉴五个主视图；长文直接在即时博客中阅读，不再占用独立导航栏。
- 全量 Bangumi 收藏分页同步，支持用户名或 `/v0/me` Token 身份识别。
- 番组档案按动画、书籍、游戏、音乐和其他分组，并支持收藏状态筛选。
- 作品详情分页拉取全部章节，显示章节标题、日期、类型与关联日志；可从日志跳回单集，也可为单集直接写吐槽。
- 作品详情可开始和结束观看场次，记录开始/结束时间、连续观看集数、实际时长与重看标记；月记自动汇总观看数据。
- 放送日历显示今天更新、本周待看和接下来要看的单集，并支持浏览全站今日放送。
- 「接下来」按动画、游戏、书籍分别维护个人队列，可调整顺序；完成当前项后自动提示同分类的下一部。春菜会根据近期在看和高分作品标签，从 Bangumi 搜索候选并说明推荐依据。
- 私人年鉴按年份汇总本地记录与收藏，评选动画、书籍、游戏、音乐、三次元作品，以及年度单集、长文、日常、标签和表情；活跃天数按日志与收藏更新日期去重合并，提供全年活跃日历、逐日活动明细、可选同比和 PNG 长图导出。
- 周记和月记自动汇总字数、正文情绪线索、在看作品与具体集数、完成作品和代表性记录；周日和每月最后一天 03:00 自动生成，错过时下次启动补生成。
- 季度追番总结按自然季度评选本季新番、弃番、最高分和最意外作品；角色档案从空白开始，可按本季作品和主角/配角筛选并直接添加角色立绘。
- 收藏短评导入、单集进度、个人评分、条目和角色短代码。
- Markdown、代码高亮、黑幕、引用、番组 TV 表情、自定义表情及生活事件。
- 剪贴板/拖拽图片压缩、九宫格预览、站内灯箱。
- 春菜使用腹黑萝莉人设，可在发布前勾选生成 20–40 字评价；未勾选时保持日志纯净。支持本地吐槽模式和 OpenAI 兼容接口，也可在应用内打开指定 AI 网页。
- 支持更换主题色、导入本地背景图片及调整背景强度。
- 本地 JSON 备份恢复、Markdown 导出、浅色/深色主题与 API 调试日志。

## AI 对话

在“系统设置 → 春菜 AI 对话”填写 API 地址和模型名称。接口应为 OpenAI 兼容格式，例如：

```text
https://api.openai.com/v1
http://localhost:11434/v1
```

API Key 仅保存在本机 `localStorage`，不会写入 JSON 备份。没有配置 AI 时，春菜仍会基于正文生成本地短评，并完成记录回顾、标签建议和标题草拟。
